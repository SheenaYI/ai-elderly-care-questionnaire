[Heading 2] 模块二｜统一情景与属性说明
[Normal] 请设想一位老人独自在家生活，家中计划安装AI养老监测系统。所有方案都具有相同的基础异常识别与报警能力，能够识别疑似跌倒、异常静止等风险，并向授权人员发出基本提醒。不同方案仅在下列三方面不同。请比较长期使用这些配置的感受，而不是假设已经发生了跌倒事件。

===== TABLE 1 (4x3) =====
属性 | 水平0 | 水平1
X1 共享层级 | 仅摘要：接收者仅查看“活动正常”“疑似跌倒”等简要提示 | 详细数据：接收者还可查看相关活动记录、视频等详细信息

===== END TABLE =====

[Normal] 统一前提：系统基础报警性能相同；云端处理/存储规则、价格、授权与暂停设置在各方案间保持一致；“详细监测”与“向接收者共享详细信息”是不同概念。没有标准答案，请选实际更愿意采用的方案。

[Heading 1] 五、是否能将12题拆成A/B两卷，每卷6题？
[Normal] 可以，而且我建议采用“随机分卷”的方案降低单人负担：每位参与者只回答A卷或B卷6道题，而不是12道全部回答。随机分卷与左右位置随机化是两件不同的事。

===== TABLE 21 (3x4) =====
版本 | 任务编号 | 同向变化题 | 替代权衡题
A卷 | T01、T02、T03、T07、T08、T11 | T01、T02、T03（3题） | T07、T08、T11（3题）
B卷 | T04、T05、T06、T09、T10、T12 | T06、T10、T12（3题） | T04、T05、T09（3题）
===== END TABLE =====

[Normal] 已核对：每卷6题，每个属性0与1各出现6次；每卷三个主效应差分矩阵秩均为3；两卷各含3道同向变化题和3道替代权衡题。全样本中每个任务仅由部分受访者完成，因此需记录卷别并随机分配，不能把两卷分别当成完整的独立研究。
[Normal] 重要取舍：6题降低疲劳，但每题样本量约减半，个体偏好信息更少；必须通过Pilot检查系数精度，必要时增加总受访者数或调整任务。A/B卷任务内容不同，因此不应直接比较“卷A更偏好某属性”而不控制设计差异。
[Normal] 同向变化题是否太容易？看参与者是否普遍快速选择低暴露方案、是否很少出现选择差异、是否反映“安全收益”理解缺失。若多题接近单边选择且贡献信息有限，应在保留可识别性和平衡性的前提下，优先改为更多反向权衡配对；修改后必须重新检查矩阵，不能只替换单题。

===== TABLE 22 (9x3) =====

[Normal] 执行建议：先进行3–5人认知访谈，观察是否真正理解属性；再招募约20–30人Pilot（尽量覆盖老人本人及照护者），这一步主要检验可行性，不宜把小样本的显著性检验当作正式结论。修订题目或配对后再小范围复测。
[Normal] 样本量提示：6题×100人得到600条选择记录，但并不等于600名独立受访者。有效样本量需结合聚类结构、预期效应、模型复杂度和Pilot估计精度进行规划。若计划比较老年人与照护者，须确保各组有足够独立参与者。
